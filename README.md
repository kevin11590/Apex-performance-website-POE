## Changelog

### Part 1 Feedback Fixes
* **HTML Validation:** Fixed unclosed container elements and standardized document structure across all pages[cite: 1].
* **Accessibility Enhancements:** Added explicit `aria-label` attributes to navigation elements and descriptive `alt` text to image elements[cite: 1].
* **Form Structure:** Added explicit `for` label attributes for all inputs in form elements[cite: 1].

### Part 2 CSS Styling & Responsive Design
* **Central External Stylesheet:** Linked `style.css` across all HTML pages[cite: 1].
* **Typography Integration:** Integrated Google Fonts (`Orbitron` and `Inter`).
* **Responsive Breakpoints:** Configured media queries at `768px` and `480px` for mobile responsiveness[cite: 1].

### Part 3 Functionality, SEO & Form Validation Implementations
* **Dynamic Content Loading:** Integrated `script.js` to dynamically load product catalogue arrays into `shop.html`[cite: 8].
* **Real-time Search Filter:** Implemented real-time array search filtering on `shop.html`[cite: 8].
* **On-Page SEO Optimization:** Added unique `<meta name="description">`, `<meta name="keywords">`, canonical title hierarchy (`h1`, `h2`), clean URLs, and alt attributes[cite: 8].
* **Off-Page & Technical SEO Setup:** Created `robots.txt` and structured `sitemap.xml` files[cite: 9].
* **Enquiry Form (`enquiry.html`):** Created dedicated form with JavaScript input validation, outputting calculated dynamic cost/time estimations[cite: 10].
* **Contact Form (`contact.html`):** Added validation that compiles user inputs into a structured `mailto:` link addressing `info@apexperformance.co.za`[cite: 10].
